# Simple Curl Desktop

## Project specification

1. Purpose
   A Windows desktop app that allows users to compose, run, and save curl requests through a simple Postman-like UI, including a dedicated booking ID field.

2. Functional requirements
   1. Build requests with HTTP method, URL, headers, and body.
   2. Dedicated Booking ID field that can be inserted into a URL path or query string.
   3. Run curl via the system binary and pass selected headers, body, and query parameters.
   4. Display response status, headers, and raw body; pretty-format JSON when applicable.
   5. Save and load requests and collections in a simplified Postman-like JSON format.
   6. Keep a local history of the last 20 requests in the session.
   7. Show clear user-facing errors when curl is missing or requests fail.
   8. Include an example request for the restful-booker API.
