# Simple Curl Desktop

A Windows desktop app for composing, running, and saving curl requests with a Postman-like interface.

## Features

- Request builder with method, URL, headers, body, and booking ID
- Booking ID insertion into URL path or query parameters
- curl execution via native OS command
- Response display with status, headers, and pretty JSON
- Save/import collection JSON in a simplified Postman-like schema
- Local request history for the last 20 requests
- Basic error handling for missing curl or failed requests

## Run locally

1. Install dependencies:
   npm install
2. Start development:
   npm run dev
3. Build app:
   npm run build

## Notes

This is an initial implementation focused on core requirements from the project specification.
